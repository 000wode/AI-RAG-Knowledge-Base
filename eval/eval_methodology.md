> 本文件定义评测的判定标准、统计口径与可追溯性规范。
> 当前运行 ID：20260917-1 ｜ 被测系统：AI-RAG-Knowledge-Base（TF-IDF 检索 + DeepSeek 生成）

---

## 1. 检索命中定义

### 1.1 判定规则表

| 题型 | 预期块 | 判定符号 | 定义 |
|------|--------|---------|------|
| 单块事实 | 单块 | `HIT` | Top-1 == 预期块 |
| 单块事实 | 单块 | `MISS` | Top-1 != 预期块 |
| 跨块 | 多块（如 1+2） | `FULL_HIT` | Top-1 ∈ 预期块 **且** 其余预期块出现在 Top-2 内 |
| 跨块 | 多块 | `PARTIAL_HIT` | Top-1 ∈ 预期块 **但** 其余预期块不在 Top-2 内 |
| 跨块 | 多块 | `MISS` | Top-1 ∉ 预期块 |
| 无答案 | 无 | `N/A` | 知识库无正确答案，检索器必然返回某块——不适用命中判定，单独评估生成层拒答行为 |
| 边界 | 单块 | `HIT` / `MISS` | 同单块事实（检索正确即可，生成层负责承认信息不足） |

### 1.2 关键说明

- **无答案题不使用 hit 字段**：检索器无相关性阈值，必然返回 Top-1；将其记为 MISS 会污染命中率统计。这类题只在生成层评估「拒答合理性」。
- **跨块题区分 FULL/PARTIAL**：Top-1 只能返回一块；若第二块不在 Top-2 内，说明检索未覆盖完整上下文。
- **命中率分母**：仅统计有明确预期块的题目（单块事实 + 跨块 + 边界 = 16 题）。

## 2. 回答正确性判定

| 判定 | 定义 | 要求 |
|------|------|------|
| `CORRECT` | 回答内容与知识库事实完全一致，无编造 | 必须给出知识库原文依据 |
| `PARTIAL` | 部分正确，或含合理的上下文外补全 | 必须指出补全内容 |
| `INCORRECT` | 与知识库矛盾或编造 | 必须指出矛盾点 |
| `REFUSED_VALID` | 无答案/边界题正确拒答或承认信息不足 | 引用拒答语句 |
| `REFUSED_INVALID` | 有答案却拒答 | 说明应回答的内容 |

---

## 3. 引用一致性判定

| 判定 | 定义 |
|------|------|
| `CONSISTENT` | 回答中每个事实陈述均可在检索到的上下文中找到出处 |
| `PARTIAL` | 回答含上下文外内容，但属于合理补全（如从问题补全主语） |
| `INCONSISTENT` | 回答含上下文外内容，且不属于合理补全（幻觉） |
| `NA` | 拒答类回答，无引用内容 |

---

## 4. 失败案例边界声明

### 4.1 计入失败

| 类别 | 判定条件 |
|------|---------|
| 检索失败 | 检索判定为 `MISS` |
| 跨块不完整 | 检索判定为 `PARTIAL_HIT` |
| 生成失败 | 回答判定为 `INCORRECT` 或 `REFUSED_INVALID` |
| 引用失败 | 回答判定为 `INCONSISTENT` |

### 4.2 不计入失败（属于预期行为）

- 无答案题返回了某文本块 —— 检索器无阈值，属已知设计边界
- 边界题拒答 —— 属正确行为
- 跨块题 Top-1 只能返回一块 —— 属单轮检索的固有限制

## 5. 延迟统计口径

### 5.1 测量方法

- 工具：Python `time.perf_counter()`
- 检索耗时 = 分词 + 余弦相似度计算（本地）
- 生成耗时 = LLM API 调用往返时间（含网络）
- 单位：毫秒（ms）

### 5.2 统计方法

- P95 计算：`sorted(times)[int(n * 0.95) - 1]`，n=20 → 取第 19 个值
- **冷启动标注**：第 1 题的检索耗时含 jieba 词典首次加载开销，单独标注，不计入稳态统计

### 5.3 运行标识规范

- 运行 ID 格式：`YYYYMMDD-N`（如 `20260915-1`）
- 每次运行记录：运行 ID、时间、环境、脚本版本、完整输出日志
- 日志存放：`eval/logs/`
